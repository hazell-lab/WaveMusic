=========================================================================
 put your music files in this folder
=========================================================================

the app expects one file per song, named after the song id in js/data.js:

    assets/audio/1.mp3    ->  song 1   "Midnight Drive"
    assets/audio/2.mp3    ->  song 2   "Neon Skies"
    assets/audio/3.mp3    ->  song 3   "Paper Satellites"
    ...
    assets/audio/64.mp3   ->  song 64  "Wildfire"

you do not need all of them. any missing file simply plays in "demo mode":
the player, progress bar, next/previous, shuffle and repeat all still work,
and a small "Demo" badge is shown in the player bar.

use royalty-free music only (free music archive, incompetech, pixabay music,
youtube audio library) and check the licence before publishing.

see README.md section 5 for the full walkthrough.
=========================================================================
